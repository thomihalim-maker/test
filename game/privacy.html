Kebijakan PrivasiPrivacy Policy · Marbot Masjid

Terakhir diperbarui / Last updated: 6 Oktober 2026 (6 October 2026)

Bahasa Indonesia

Marbot Masjid adalah game santai untuk anak-anak. Kami tidak mengumpulkan data pribadi apa pun.

  • Tidak ada akun, iklan, analitik, pelacakan, atau pembelian dalam aplikasi.
  • Game tidak mengirim data apa pun lewat internet. Setelah dimuat, game bisa dimainkan sepenuhnya offline.
  • Progres permainan (hari, koin, bangunan masjid, hewan, pengaturan suara dan bahasa) hanya disimpan di perangkat ini (penyimpanan lokal browser atau aplikasi). Data ini tidak pernah keluar dari perangkat dan tidak bisa kami lihat.
  • Progres bisa dihapus kapan saja lewat Pengaturan → Hapus Progres di dalam game, dengan menghapus data situs di browser, atau dengan menghapus aplikasi.
  • Versi web disajikan oleh layanan hosting (GitHub Pages). Seperti semua situs web, server hosting dapat mencatat data teknis standar (mis. alamat IP) saat file game diunduh; lihat pernyataan privasi GitHub. Aplikasi Android menyimpan semua file game di dalam aplikasi.

Pertanyaan tentang privasi dapat diajukan melalui halaman proyek.

English

Marbot Masjid is a cozy game for children. We do not collect any personal data.

  • No accounts, ads, analytics, tracking or in-app purchases.
  • The game does not send any data over the internet. Once loaded, it can be played completely offline.
  • Game progress (day, coins, mosque building, animals, sound and language settings) is stored only on this device (browser or app local storage). It never leaves the device and we cannot see it.
  • Progress can be deleted at any time with Settings → Reset Progress in the game, by clearing the site's data in the browser, or by uninstalling the app.
  • The web version is served by a hosting provider (GitHub Pages). Like any website, the hosting servers may log standard technical data (such as IP addresses) when the game files are downloaded; see GitHub's privacy statement. The Android app ships all game files inside the app.

Privacy questions can be raised on the project page.
